As part of this project, I developed a desktop application for library management using C#, WPF, and an SQLite database. The interface was designed in XAML, while the application logic was organized according to the MVVM architecture, making the code easier to maintain and extend.

The application allows users to view the list of books, add new books, edit existing information, and delete records that are no longer needed. I also implemented a search function that filters books in real time by title, author, or genre, allowing users to quickly find the desired information.

By completing this project, I strengthened my knowledge of desktop application development in C#, SQLite database management, and the implementation of MVVM principles in WPF applications.
